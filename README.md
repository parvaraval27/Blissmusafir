
  # Design Travel Blog Website

  This is a code bundle for Design Travel Blog Website. The original project is available at https://www.figma.com/design/0ISNl57kEklyaFOEqSyGy6/Design-Travel-Blog-Website.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.

  Note: Routing has been migrated from a manual page-switching implementation to `react-router-dom` (BrowserRouter + Routes). Internal links and navigation now use `Link`, `NavLink`, `useNavigate`, and `useParams`. If you previously used the `onNavigate` prop, switch to the React Router APIs when adding new navigation logic.
